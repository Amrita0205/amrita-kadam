# amrita-kadam.vercel.app

Personal portfolio of **Amrita Kadam**: final-year B.Tech CSE at IIIT Raichur and mechanistic interpretability research intern at Moleculyst.

**Live:** https://amrita-kadam.vercel.app

Built with React, TypeScript, Vite and Tailwind CSS. Deployed on Vercel.

```sh
npm install
npm run dev     # local development
npm run build   # production build
```

Resume: `src/assets/Resume.pdf`. The site's experience, projects and skills are kept word-for-word in sync with it.
